# Icons

The Sediment icon shows three sheets of the same line chart, stacked. The top sheet is the full chart. The middle sheet is the same image at 18 x 18 cells. The bottom sheet is at 10 x 10 cells. Older data is coarser. The spike stays visible on every sheet. A clock with a reverse arrow (MDI `history`) sits at the lower right, on a cut-out disc.

| File | Use |
| --- | --- |
| `sediment.svg` | Source. Dark rounded tile `#1f2933`, neutral `#e2e5e8`, accent `#18bcf2`, sheets `#29363f`. |
| `sediment-512.png` | GitLab project avatar. |
| `sediment-128.png` | README header and release notes. |
| `sediment-transparent.svg` | The same icon without the tile, for light themes. Generated by `bare.py`. |
| `sediment-transparent-dark.svg` | The same, with lighter sheets and a light clock, for dark themes. |
| `bare.py` | Builds the two transparent SVGs and the brand PNGs from `sediment.svg`. |
| `../../custom_components/sediment/brand/icon.png`, `icon@2x.png` | Home Assistant brand icon for light themes, transparent, 256 x 256 and 512 x 512. |
| `../../custom_components/sediment/brand/dark_icon.png`, `dark_icon@2x.png` | The same for dark themes. |
| `drafts/` | All earlier candidates, the generator scripts and their preview sheets. |

There is no `logo` file. The icon is square, so the Home Assistant brands rules let it serve as the logo too. The brand icons have no tile, because Home Assistant draws integration icons on its own background. The gaps between the sheets and around the clock are real cut-outs. The light variant keeps the dark sheets and a dark clock. The dark variant has lighter sheets and a light clock, because dark sheets vanish on a dark card. The tile version stays for the GitLab avatar and the README.

## Colors

The accent is the Home Assistant logo blue `#18bcf2`. Contrast on the tile is 6.68:1. The OKLab distance to the neutral is 0.159 under protanopia, 0.218 under deuteranopia and 0.201 under tritanopia. All three are above the 0.10 minimum. The numbers are in `drafts/palette-r5.json`.

## How to regenerate

`py -3 -m pip install --user resvg-py Pillow`, then `py -3 assets/icons/drafts/r5.py --export` for the tile version and the avatar, and `py -3 assets/icons/bare.py` for the transparent brand icons.
